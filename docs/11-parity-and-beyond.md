# 11 · 对标矩阵与超越点（Parity & Beyond）

> 状态：**现行**。口径：**个人版完全对标 Grok Bot，并在 6 个维度超越；团队协作 / 会议 / 企业管控 / 语音明确不做。**
> 依据：Grok Bot 官方文档（[grok-bot](https://docs.x.ai/grok-bot/overview)）；差距方法见 [gap-vs-grokbot.md](gap-vs-grokbot.md)（历史）。

---

## 1. 对标口径

- **对标对象**：Grok Bot 的**个人版能力**（一个 owner、多个 Bot、自己的电脑与工具）。
- **不对标**：Team Bots、群聊、会议、企业 IAM、语音、计费 SaaS —— 见 §4。
- **判定**：`= 对标`（功能等价）/ `+ 超越`（我们更强或它没有）/ `— 不做`（明确排除）。

## 3. 超越点（为什么用 jaryn 而不是 Grok Bot）

1. **隔离粒度**：每 Bot 一台电脑 + 任务级快照，一个 Bot 玩坏不连累其他（Grok Bot 是每用户一台）。
2. **数据主权**：私有化部署，数据不出门；可完全断网用（本地模型 + 内网 IM）。
3. **成本可控**：模型可换（DeepSeek 便宜）、预算硬上限、空闲休眠；没有不透明的周额度。
4. **可审计可回放**：每个事件、工具、审批都可回放；出问题能定位到哪一步。
5. **可扩展**：插件化 + 开放格式；连接器/工具/通道都能第三方实现。
6. **中文与本地化**：飞书/企微原生、中文错误与文档；Grok Bot 基本不做。

---

## 4. 明确不做（写死，避免范围蔓延）

| 类别 | 具体 | 原因 |
|---|---|---|
| **团队协作** | Team Bots、共享 Bot、人类群聊、团队记忆审核、多人权限、Slack/Teams 多人接入、共享云电脑 | 单 owner 产品；多用户会带来 IAM/隔离/审计的指数级复杂度 |
| **会议** | Google Meet/Zoom/Teams 入会、会议纪要、实时语音 | 依赖实时音视频基础设施，与"个人 AI 同事"核心无关 |
| **企业管控** | SAML/OIDC/SCIM、网络策略、TLS 检视、inference hooks、组织 API、审计导出、数据保留策略、设备合规、计费/席位 | 企业销售与合规是另一家公司的事 |
| **语音** | TTS 朗读、语音通话、语音消息 | 个人版优先文字 + 客户端；语音以后单独评估 |
| **SaaS** | 多租户、按席位计费、托管服务 | 本项目是自托管产品，不做运营 |

> 这些"不做"会写进 PRD 的 Won't 列表与路线图的"绝不排期"；新增需求先对照此表。

## 5. 版本阶梯（个人版完全对标）

| 版本 | 内容 | 状态 |
|---|---|---|
| **v0.1** | 运行时 + **Web UI** + 记忆 + 例程 + 多 Bot（单 owner） | **进行中** |
| **v0.2** | 云电脑（浏览器/终端、看屏接管、快照、本机出网） | 下一阶段 |
| 不做 | 真实支付网关/结算、IM 通道、原生 iOS、真 WebRTC | Won't |

> 所有阶段都是"可停可交付"：v0.1 后已能每天用；v0.2 云电脑后覆盖 Grok Bot 的核心演示场景；v1.9 已补齐审计缺口。**Won't 清单不接受需求**（[17](17-scope-and-wont.md)）。

## 6. 成功指标（个人版）

| 指标 | 目标 |
|---|---|
| 每日主动消息接受率 | ≥ 30% |
| 需人工接管的网页任务比例 | ≤ 20% |
| 任务一次完成率（无人工重试） | ≥ 60% |
| 凭据泄漏事件 | 0 |
| 单任务平均成本 | ≤ 同任务 Grok Bot 的 60%（估算） |
| 崩溃恢复成功率 | 100%（回放测试） |

## 7. 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| 云电脑反爬/风控 | 网页任务失败率 | 本机出网、人工接管兜底、不承诺绕过反爬 |
| OAuth 应用审核（Gmail 等） | 连接器上线延迟 | 先用 IMAP/device-code；第三方 MCP 兜底 |
| 浏览器自动化可靠性 | 体验差 | 录制回放 + 失败重试 + 人工接管 |
| Vault 安全审计 | 高危 | 开源 + 外部审计 + 默认最小权限 |
| 单人维护范围 | 范围失控 | v0.1 先跑通；边界由 Won't 清单固定（[17](17-scope-and-wont.md)） |

---

## 8. 结论

**个人版可以对标 Grok Bot，并在隔离、数据主权、成本、可审计、扩展性、中文本地化六点上超越。当前 v1.9.0 已交付全部规划能力（162 测试）；不承诺日期。明确不做：真实支付网关/结算、IM 通道、团队/会议/企业/语音/多租户、原生 iOS（[17](17-scope-and-wont.md)）。**
