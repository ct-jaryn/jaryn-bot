# 00 · 产品需求文档（PRD）

> 状态：**现行**。目标：**个人版完全对标 Grok Bot，并在 6 个维度超越；团队协作 / 会议 / 企业管控 / 语音明确不做。**
> 已拍板：单 owner · 云服务器 · **Web 优先** · 默认云 API · 容器云电脑 · **4C4G 机器** · AGPL-3.0 + 商业双许可。
> 边界：**真实支付网关/结算、IM 通道、团队/会议/企业管控/语音/多租户、原生 iOS 明确不做**（见 [17 不做清单](17-scope-and-wont.md)）。
> 对标矩阵见 [11-parity-and-beyond.md](11-parity-and-beyond.md)；配套：[01 功能规格](01-functional-spec.md) · [03 规划](03-roadmap.md) · [文档地图](README.md)
> 最后更新：2026-11-23

## 1. 产品是什么

**jaryn-bot = 跑在你自己服务器上的个人 AI 同事。**

它在自己的电脑（云容器）里干活：开浏览器、跑终端、写文档、查资料、收发邮件；你通过客户端或 IM 派活，过程中流式汇报，危险动作弹审批卡；你不在线时按计划主动干活，甚至主动提议该做什么。

**它不是**（写死，避免范围蔓延）：
- 不是团队协作工具（没有多人账号、共享 Bot、人类群聊、团队记忆）；
- 不是会议机器人（不入会、不做纪要、不做实时语音）；
- 不是企业管控平台（没有 SSO/SCIM/网络策略/组织 API/审计导出）；
- 不是 SaaS（自托管、单 owner、不按席位计费）。

**与 Grok Bot 的关系**：个人能力**完全对标**（见 [11](11-parity-and-beyond.md) §2），并在隔离粒度、数据主权、成本透明、可审计、可扩展、中文本地化上**超越**；它最重的团队/会议/企业部分**不做**。

## 2. 用户

| 用户 | 描述 | 核心诉求 |
|---|---|---|
| **P1 你自己**（唯一目标用户） | 有云服务器、会 Docker；日常写代码/查资料/写文档/盯项目 | 一个 Web 入口把"查/写/跑/盯/收发"交给它；数据自己拿；花费可控；机器只要 4C4G |
| **P2 开源社区贡献者** | 认同设计、愿意提交插件或 PR | 可读设计、可本地跑起来、可扩展 |

**非目标用户**：团队/企业采购方、非技术用户、需要开箱即用 SaaS 的人。

## 5. 非功能需求

| ID | 需求 | 指标 |
|---|---|---|
| NFR-1 | 单机可跑 | `docker compose up` 10 分钟内首轮对话 |
| NFR-2 | 恢复 | `kill -9` 后重启会话/产物不丢，进行中轮次可续 |
| NFR-3 | 响应 | 首 token <3s；工具状态 1s 内可见 |
| NFR-4 | 预算 | token/费用/步数可配；超限 5s 内停止 |
| NFR-5 | 安全 | 危险动作默认审批；密钥不入 prompt/日志/截图 |
| NFR-6 | 隔离 | 每 Bot 独立 workspace；跨 Bot 不可读 |
| NFR-7 | 可观测 | 工具/审批/记忆/凭据操作有审计；`replay` 可复现 |
| NFR-8 | 可扩展 | 新通道/工具/连接器 = 插件，不改核心 |
| NFR-9 | 可升级 | DB 迁移版本化；破坏性拒绝启动 |
| NFR-10 | 成本 | 同任务 ≤ Grok Bot 类方案 60%（估算） |
| NFR-11 | 体积 | 单镜像 <500MB（不含云电脑镜像） |
| NFR-12 | 中文优先 | 中文文档/错误/IM |
| NFR-13 | 私有化边界 | 数据与密钥本地；出网仅模型/IM/连接器（可替换） |
| NFR-14 | 多端一致 | 多设备同一事件流；重连 <5s 补齐；审批幂等 |
| NFR-15 | 云电脑隔离 | 容器逃逸测试全部阻断；跨 Bot 网络不可达 |
| NFR-16 | 凭据零泄漏 | 模型上下文/日志/事件/截图中无密码明文（自动断言） |
| NFR-17 | 记忆低耗 | 每轮 digest ≤600 token；检索 p95 <20ms；写入 0 LLM；整理 ≤1 次 LLM/天；无向量库/embedding 默认依赖 |

## 8. 假设、依赖与风险

**假设**：用户有常开云服务器（4C4G）；接受 **Web 单入口**；模型 API 可用；Docker/容器可用。

**关键依赖**：模型 API；Chromium 在容器内可用（office 生成不依赖 LibreOffice）；本机出网需要一台在线客户端；OAuth 需部署者自建应用（链路已实现）；IM 平台不需要（明确不做）。

| 风险 | 影响 | 缓解 |
|---|---|---|
| 云电脑反爬/风控 | 网页任务失败 | 本机出网、人工接管、不承诺绕过 |
| 浏览器自动化可靠性 | 体验 | 录制回放 + 重试 + 接管兜底 |
| 云电脑资源 | 4C4G 吃紧 | 单云电脑并发、5 分钟休眠、Bot 容器配额 |
| 单人维护范围失控 | 半途而废 | 小步发版 + Won't 清单；每阶段可交付 |
| 边界漂移（做着做着扩范围） | 资源分散 | [17 不做清单](17-scope-and-wont.md) 变更需改文档，不能只在聊天同意 |
| 成本失控 | 主动任务烧钱 | 预算硬上限 + 熔断 |
